# Typography decision

The selected direction uses JetBrains Mono 400 for file metadata and column headings. The interface sans remains in place for filenames, prose, navigation, and controls. `--font-data` is `"JetBrains Mono", ui-monospace, SFMono-Regular, Consolas, monospace`; `--font-ui` and `--font-code` keep their existing roles.

The owner selected the metadata-plus-headings sample after comparing baseline, metadata, metadata-plus-headings, and metadata-plus-headings-plus-filenames in the app and catalogue. The final production samples are captured under `.impeccable/review/syl68-selected/`.

Comparison evidence recorded for SYL-68: Nextcloud 35 theming documentation showed sans-serif labels and compact vertical controls. File Browser Next's unversioned settings documentation showed sans-serif headings and prose. These were static documentation screenshots; no live competitor interaction was assessed.
